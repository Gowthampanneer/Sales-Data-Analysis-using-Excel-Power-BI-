# Sales Data Analysis Using Excel & Power BI

## Project Overview

This project focuses on analyzing sales data using Microsoft Excel and
Power BI. The goal is to organize the data, identify useful sales
patterns, and present findings through clear visualizations that support
data-driven decision-making.

## Project Objectives

-   Review and prepare sales data for analysis.
-   Use Excel for data cleaning, calculations, and preliminary analysis.
-   Build a Power BI dashboard to present sales information visually.
-   Identify trends, compare performance, and highlight areas that may
    need attention.
-   Communicate findings in a clear and understandable format.

## Tools Used

-   **Microsoft Excel** --- data review, cleaning, calculations, and
    analysis.
-   **Microsoft Power BI** --- data visualization and dashboard
    development.

## Project Workflow

1.  **Data preparation:** Inspect the source data and check for missing,
    duplicate, or inconsistent values.
2.  **Data analysis:** Use Excel to organize the data and perform
    relevant calculations.
3.  **Dashboard development:** Import the prepared data into Power BI
    and create visuals that make the results easier to understand.
4.  **Review:** Check that the visuals and calculations accurately
    represent the source data.
5.  **Documentation:** Record the project purpose, methodology, and
    findings in the project report.

## Key Questions to Explore

Depending on the columns available in the dataset, the analysis may
explore: - How sales change over time. - Which products or categories
contribute most to sales. - Which regions, stores, or customer groups
perform well. - Where performance differs across available segments. -
What patterns or opportunities are visible in the data.
